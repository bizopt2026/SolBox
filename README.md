# Sub-3 훈련 체크

2027.3.21 서브3(2:59:59) 18주 + 레이스 주 훈련계획(11/9 → 3/21, 11/22 인천마라톤 포함)를 휴대폰에서 체크하는 웹앱.

- `app/index.html` — 단일 파일 앱 (claude.ai Artifact로 게시해 휴대폰에서 사용)
- 내 페이스: 역치 심박·역치 페이스·최근 5K/10K/하프 기록으로 VDOT를 계산해 훈련표 전체 페이스·심박 기준·점검 목표를 개인화
- 처음 사용 안내: 첫 접속 시(업데이트 후 기존 사용자에게도 새 소식과 함께 한 번) 8단계 안내(훈련 체크·내 페이스·목표 정하기·크루·크루 초대·기록·홈 화면 추가), 가이드 탭에서 다시 보기

- 내 계획 바꾸기(나에게만 적용): 요일 교환(롱런 일요일로 등), 주간 거리 80~110%(이지·LSD만), 날짜별 훈련 수정, 클로드에게 부탁(제안 확인 후 적용), 되돌리기·원래 계획으로
- 식단 기록: 음식 사진·글로 AI가 칼로리·탄수·단백질·지방 추정 → 확인·수정 후 저장, 훈련 종류·체중별 하루 목표와 비교, AI 코치와 연결(사진은 저장 안 함)
- COROS 분석 데이터 자동 갱신: 역치 페이스·10K 예측(내 페이스), VO2max·예측 기록, 훈련 부하·회복률(컨디션 카드·AI 코치), 역치 심박은 COROS 미제공으로 직접 입력
- 랩 분석: COROS 직접 끊은 랩(없으면 1km 구간)·TCX·FIT 랩을 날짜별 표로(구간 판정, 본 구간 요약), AI 코치에게 랩 분석 요청
- 인스타 스토리: 그날 훈련 기록(계획·거리·페이스·시간·심박·본 구간 랩)과 AI 코치 코멘트를 내 사진 위에 얹은 1080×1920 이미지 저장 · 초 단위 페이스 선 그래프(COROS 원본 FIT·가져온 FIT)와 랩 평균 표시, 심박 음영, 또는 랩 표
- 레이스 전략(내 페이스): 대회 코스 GPX → 고도 반영 km별 목표 페이스·통과 시간·고도 차트 + AI 구간 전략·보급·주의점, 대회별 이력 관리 · 대회 후 연동 기록(COROS 1km 랩·초 단위 기록·파일)으로 계획 대비 분석, 100점 만점 평가(목표 40·분배 25·계획 준수 20·후반 15)와 다음 레이스 유의사항 · 전략 텍스트 복사(공유), COROS 워치 워크아웃 등록(90일 안이면 대회 날 일정, 아니면 라이브러리)
- 훈련 점수: 완료한 날을 100점 만점(양보다 질: 거리 30 + 질 70 — 본 구간 페이스 정확도·반복 편차·심박 / 이지 날 페이스·심박 절제)으로 매겨 90+ 파랑·80+ 초록·70+ 노랑·60+ 주황·60 미만 빨강으로 이번 주 점·완료 버튼·훈련표 체크에 표시, 놓친 날은 빈 빨간 점 · 휴식일 추가 러닝: '추가 러닝' 표시, 체크 없이 주간 거리 합산, 편하게 뛰었는지(페이스 50·심박 50, 10km 초과 −10)로 별도 점수, 크루 피드·주간 현황(주황 테두리 점)에 공유 · 크루원 점도 거리 기준 점수 색 · 식단 점수(열량·탄수·단백질·지방 목표 대비 100점 만점)
- AI 코치: 오른쪽 아래 버튼, 내 계획·달린 기록·체중·목표·페이스 존을 근거로 답변(대화는 내 계정에만 저장) · 음성(말로 묻기·답변 읽어주기)
- 훈련 전 컨디션: 안정시 심박(평소 7일 평균 대비)·수면 HRV(COROS)·잠 상태로 좋음/주의/쉬어가기 판정, 수·토는 계획서 원칙대로 하루 미루기 안내, 직접 입력 가능
- 오늘: 그날 훈련, 완료 체크, 실제 거리·심박·페이스·메모, 이번 주 진행, 요일별 식단
