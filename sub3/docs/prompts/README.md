# 써브쓰리 복제본 업데이트 프롬프트 (날짜별)

원본 앱의 변경 내용을, 이미 복제해서 쓰는 앱에 반영하는 작업 지시 프롬프트예요.
파일 내용을 통째로 복사해서 **복제한 앱을 만든 Claude 대화**에 붙여 넣고, 위쪽 `<여기에 내 앱 링크>`만 그 앱 링크로 바꾸면 돼요.

**날짜 순서대로** 적용하세요. 각 프롬프트는 앞 날짜를 적용한 앱을 기준으로 만들었어요.

> **버전별 프롬프트:** 버전이 오를 때마다 자동으로 만든 프롬프트가 [versions/](versions/README.md)에 있어요. 내 복제본 버전(가이드 → 기타 → 버전 관리)을 확인하고, 그 다음 버전부터 차례로 적용해도 돼요.

- 모든 프롬프트는 복제본의 **버전 값(APP_VERSION·VLOG)을 바꾸지 않아요.** 앱 안에서 '업데이트 확인'으로 원본 버전을 받으면 버전 값도 원본과 같아져요.
- **v1.8.0(2026-11-25)부터는 프롬프트 없이** 가이드 → 기타 → 버전 관리 → '업데이트 확인'으로 새 버전을 받아요. 그 전에 복제한 앱은 2026-11-25 프롬프트 하나만 적용하면 돼요.
- 그날 원본을 고친 뒤 이 폴더의 그날 파일에 내용을 이어서 정리해요. 같은 날 여러 번 고쳐도 파일은 하루에 하나예요.
- 적용이 번거로우면, 원본을 새로 복제하고 가이드 → 백업으로 기록을 옮기는 방법이 가장 간단해요(최신 기능이 모두 들어와요).
