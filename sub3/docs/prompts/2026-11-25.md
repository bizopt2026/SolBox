# 작업 지시: 2026-11-25 업데이트 (최종본 · v1.8.2 기준: 복제한 앱도 업데이트 확인으로 새 버전 받기, 업데이트 버튼을 위로)

> 아래 전체를 복사해서, **복제한 '써브쓰리'(예전 이름 Sub-3 훈련 체크) 앱을 만든 Claude 대화**에 붙여 넣으세요.
> `<여기에 내 앱 링크>` 자리에 내 앱(복제본) 링크를 넣어 주세요.
> **2026-11-20 최종본 프롬프트를 먼저 적용한 앱**(v1.7.5)을 기준으로 만들었어요.

> **이 프롬프트 하나만 적용하면 그다음부터는 앱 안(가이드 → 기타 → 버전 관리 → 업데이트 확인)에서 최신 버전을 바로 받아요.** 앞 버전 프롬프트를 다 적용하지 않은 앱이어도 이것만 적용한 뒤 '업데이트 확인'을 누르면 돼요(찾기 문자열이 조금 달라도 같은 자리에 넣어 달라고 적어 뒀어요).

---

내 아티팩트 "써브쓰리"(예전 이름 "Sub-3 훈련 체크")에 아래 업데이트를 적용해서 **같은 URL에 다시 게시**해 줘.

- 아티팩트: <여기에 내 앱 링크>

## 0. 먼저 지킬 것
1. `artifact-capabilities` 스킬과 `artifact-design` 스킬을 먼저 로드해.
2. 아티팩트를 `read`로 읽고, **그 원본 파일을 고쳐서** 같은 `url`로 재게시해. 새 아티팩트를 만들지 마.
3. 게시할 때 `contract`는 넘기지 마. **이번에는 `capabilities`를 넘겨:** `read` 결과의 저장된 권한 선언(`artifact-stored-declaration`)을 그대로 옮기고 `"artifact": {}` 하나만 더해(다른 항목은 빼거나 바꾸지 마). 이 권한이 있어야 앱이 업데이트할 때 자기 자신을 다시 게시할 수 있어.
4. 아래에 적은 곳만 고치고, 다른 기능은 건드리지 마.
5. 버전 값(APP_VERSION·VLOG)은 바꾸지 마. 복제한 앱의 버전(`APP_VERSION`, `APP_RELEASED`, `VLOG`)은 복제 시점 값으로 고정해서 관리해.
6. '찾기' 문자열은 파일에서 한 번만 나와. 그대로 없으면 같은 역할을 하는 곳을 찾아 같은 결과가 나오게 고치고, 무엇을 바꿨는지 알려줘.

## 1. 바뀌는 내용
- **복제한 앱도 업데이트 확인으로 새 버전 받기**
- 가이드 → 기타 → 버전 관리에 '업데이트 확인'이 생겼어요. 원본이 새 버전으로 바뀌면 복제한 앱의 주인이 버튼 한 번으로 같은 버전으로 바꿀 수 있고, 훈련·체중·식단 기록은 그대로 남아요. 하루 한 번 앱을 열 때 조용히 확인해서 새 버전이 있으면 알려 줘요. 이 버전부터 복제한 앱에서 쓸 수 있어요(아티팩트 자기 게시 기능 허용).
- **업데이트 버튼을 위로(v1.8.2)**: 새 버전이 있으면 상단 머리글에 '업데이트' 버튼이 보이고, 누르면 가이드 → 버전 관리 카드가 펼쳐져요. 버전 관리 카드는 업데이트 칸을 맨 위로 올리고 '새 버전 vX.Y.Z' 바로 옆에 업데이트 버튼을 두었어요.
