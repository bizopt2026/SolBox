# 복제본 업데이트: v1.8.3 (2026-11-25) 메인 색을 딥 틸로

> 아래 전체를 복사해서, **복제한 '써브쓰리'(예전 이름 Sub-3 훈련 체크) 앱을 만든 Claude 대화**에 붙여 넣으세요.
> `<여기에 내 앱 링크>` 자리에 내 앱(복제본) 링크를 넣어 주세요.
> **v1.8.2까지 적용한 앱**을 기준으로 자동 생성했어요(원본 v1.8.2 → v1.8.3 차이).

---

내 아티팩트 "써브쓰리"(예전 이름 "Sub-3 훈련 체크")에 아래 업데이트를 적용해서 **같은 URL에 다시 게시**해 줘.

- 아티팩트: <여기에 내 앱 링크>

## 0. 먼저 지킬 것
1. `artifact-capabilities` 스킬과 `artifact-design` 스킬을 먼저 로드해.
2. 아티팩트를 `read`로 읽고, **그 원본 파일을 고쳐서** 같은 `url`로 재게시해. 새 아티팩트를 만들지 마.
3. 게시할 때 `capabilities`와 `contract`를 넘기지 마. 기존 권한 선언을 그대로 이어가.
4. 아래에 적은 곳만 고치고, 다른 기능은 건드리지 마.
5. 버전 값(APP_VERSION·VLOG)은 바꾸지 마. 복제한 앱의 버전(`APP_VERSION`, `APP_RELEASED`, `VLOG`)은 복제 시점 값으로 고정해서 관리해.
6. '찾기' 문자열은 파일에서 한 번만 나와. 그대로 없으면 같은 역할을 하는 곳을 찾아 같은 결과가 나오게 고치고, 무엇을 바꿨는지 알려줘.

## 1. 바뀌는 내용
- **메인 색을 딥 틸로**
- 버튼·강조에 쓰던 붉은 계열(레이스 오렌지)을 차분한 딥 틸(청록)로 바꿨어요. 어두운 화면에서는 밝은 청록으로 보여요. 인스타 스토리·레이스 인포그래픽 이미지의 강조색도 같이 바꿨고, 겹치지 않게 훈련표 테이퍼 주간 색은 연보라로 바꿨어요. 점수 색(파랑·초록·노랑·주황·빨강)은 그대로예요.
