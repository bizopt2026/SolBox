# 복제본 업데이트: v1.7.5 (2026-11-20) 입력할 때 화면 확대 없애기

> 아래 전체를 복사해서, **복제한 '써브쓰리'(예전 이름 Sub-3 훈련 체크) 앱을 만든 Claude 대화**에 붙여 넣으세요.
> `<여기에 내 앱 링크>` 자리에 내 앱(복제본) 링크를 넣어 주세요.
> **v1.7.4까지 적용한 앱**을 기준으로 자동 생성했어요(원본 v1.7.4 → v1.7.5 차이).

---

내 아티팩트 "써브쓰리"(예전 이름 "Sub-3 훈련 체크")에 아래 업데이트를 적용해서 **같은 URL에 다시 게시**해 줘.

- 아티팩트: <여기에 내 앱 링크>

## 0. 먼저 지킬 것
1. `artifact-capabilities` 스킬과 `artifact-design` 스킬을 먼저 로드해.
2. 아티팩트를 `read`로 읽고, **그 원본 파일을 고쳐서** 같은 `url`로 재게시해. 새 아티팩트를 만들지 마.
3. 게시할 때 `capabilities`와 `contract`를 넘기지 마. 기존 권한 선언을 그대로 이어가.
4. 아래에 적은 곳만 고치고, 다른 기능은 건드리지 마.
5. 버전 값(APP_VERSION·VLOG)은 바꾸지 마. 복제한 앱의 버전(`APP_VERSION`, `APP_RELEASED`, `VLOG`)은 복제 시점 값으로 고정해서 관리해.
6. '찾기' 문자열은 파일에서 한 번만 나와. 그대로 없으면 같은 역할을 하는 곳을 찾아 같은 결과가 나오게 고치고, 무엇을 바꿨는지 알려줘.

## 1. 바뀌는 내용
- **입력할 때 화면 확대 없애기**
- 가이드 → 백업 → 복원하기를 누르면 휴대폰 화면이 확대되던 문제를 고쳤어요. 휴대폰에서는 글을 입력하는 모든 칸의 글자를 16px로 맞춰, 입력칸을 눌러도 화면이 확대되지 않아요.

## 2. 고칠 곳 (위에서부터 차례로, 2곳)

**1. (CSS)**

찾기:
```
placeholder{font-size:13px}
</style>

<header class=
```
바꾸기:
```
placeholder{font-size:13px}
/* phones zoom the page when a field under 16px gets focus: keep every typing field at 16px on touch screens */
@media (pointer:coarse){input:not([type=checkbox]):not([type=radio]):not([type=range]):not([type=file]),textarea,select{font-size:16px!important}}
</style>

<header class=
```

**2.**

찾기:
```
margin-top:10px;font-size:12px" hidden></textarea><button
```
바꾸기:
```
margin-top:10px;font-size:16px" hidden></textarea><button
```

## 3. 확인하고 알려줘
- 문법 오류 없이 페이지가 열리는지
- 위 '바뀌는 내용'대로 보이고 동작하는지
- 게시 후 저장된 권한 선언이 이전과 같은지
