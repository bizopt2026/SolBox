# 써브쓰리 · 버전 관리 규칙

지금 버전: **1.8.1** (2026-11-25)

## 번호 형식: MAJOR.MINOR.PATCH

| 자리 | 언제 올리나 | 예 |
|---|---|---|
| **MAJOR** | 저장 데이터 구조가 바뀌어 예전 백업 코드와 호환이 깨질 때 · 탭 구성이나 핵심 흐름을 크게 바꿀 때 · 기존 기능을 없앨 때 | 1.4.2 → 2.0.0 |
| **MINOR** | 새 기능·새 화면·새 연동(커넥터 기능 추가 포함)을 넣을 때 · 기존 기능을 눈에 띄게 확장할 때 | 1.0.3 → 1.1.0 |
| **PATCH** | 버그 수정 · 문구·UI 다듬기 · 계산 보정 · 성능 개선 | 1.1.0 → 1.1.1 |

- 원본을 고쳐서 **게시할 때마다 한 번** 올려요. 한 번의 게시에 여러 변경이 섞이면 가장 큰 범위 하나만 올려요.
- 윗자리를 올리면 아랫자리는 0으로 돌려요.
- 커넥터 권한 선언을 바꾸면(사용자가 다시 허용해야 함) MINOR 이상으로 올리고, 변경 기록에 적어요.

## 코드 위치 (`app/index.html` 메인 스크립트 맨 위)

```js
var APP_VERSION="1.0.0",APP_RELEASED="2026-11-15";
var VLOG=[ ["버전","YYYY-MM-DD","한 줄 요약","자세한 내용(선택)"], … ];  // 최신이 맨 앞
```

버전을 올릴 때:
1. `APP_VERSION`과 `APP_RELEASED`를 바꿔요.
2. `VLOG` 맨 앞에 새 항목을 추가해요.
3. `python3 tools/version_prompt.py`로 이 버전의 복제본 프롬프트(`docs/prompts/versions/vX.Y.Z.md`)를 자동으로 만들어요. 직전 버전과의 차이를 '찾기 → 바꾸기'로 정리하고, 버전 값은 빼고, 스스로 적용·검증까지 해요.
4. 커밋 메시지 맨 앞에 `vX.Y.Z`를 붙여요(생성된 프롬프트도 같은 커밋에).

가이드 → 기타 → **버전 관리** 카드에 지금 버전, 규칙, 변경 기록이 보여요.

## 복제한 앱

- **v1.8.0부터 복제본도 앱 안에서 업데이트해요.** 가이드 → 기타 → 버전 관리 → '업데이트 확인'을 누르면 원본의 새 버전을 받아 자기 자신을 다시 게시해요(권한 `artifact`). 기록(계정 저장소·이 기기 저장)은 그대로 남고, 버전 값도 원본과 같아져요. 하루 한 번 앱을 열 때 조용히 확인해서 새 버전이 있으면 알려 줘요. 편집할 수 있는 주인만 업데이트할 수 있어요.
- 새 버전은 main 에 `sub3/app/index.html`이 들어오면 GitHub Actions(`.github/workflows/sub3-npm.yml`)가 `sub3/npm/build.mjs`로 묶어 npm 패키지 `@gulex3/sub3@<APP_VERSION>`으로 올려요(같은 버전이 이미 있으면 건너뜀). 앱은 `@latest`와 다음 번호(PATCH+1~3 · MINOR+1 · MAJOR+1)를 jsDelivr에서 불러 가장 높은 버전을 찾아요. 그래서 **버전은 항상 올리기만** 해요(같은 번호로 다시 올리면 npm에 반영되지 않아요).
- v1.8.0보다 먼저 복제한 앱은 업데이트 권한이 없어요. `docs/prompts/2026-11-25.md`(또는 `versions/v1.8.0.md`) 프롬프트 하나만 적용하면 그다음부터 앱 안에서 받아요. 이 프롬프트는 예외로 `capabilities`에 `artifact`를 더해 게시하게 적혀 있어요(`tools/version_prompt.py --all`로 다시 만들면 손으로 고친 이 부분을 되살려야 해요).
- 업데이트 프롬프트(버전별 `docs/prompts/versions/vX.Y.Z.md`, 날짜별 `docs/prompts/YYYY-MM-DD.md`)를 손으로 적용할 때는 버전 값을 건드리지 않게 프롬프트에 적어 둬요.
- 앱은 열린 주소가 원본 링크와 다르면 '복제본' 표시를 붙여요. 주소를 알 수 없으면 '버전'으로 보여요.
- 새 버전에 권한(`capabilities`) 추가가 필요하면, 앱 안 업데이트만으로는 권한이 늘지 않아요. 그런 버전은 날짜별 프롬프트에 권한 추가 방법을 적어요.
