# 복제본 업데이트 프롬프트 (날짜별)

원본 앱의 변경 내용을, 이미 복제해서 쓰는 앱에 반영하는 작업 지시 프롬프트예요.
파일 내용을 통째로 복사해서 **복제한 앱을 만든 Claude 대화**에 붙여 넣고, 위쪽 `<여기에 내 앱 링크>`만 그 앱 링크로 바꾸면 돼요.

**날짜 순서대로** 적용하세요. 각 프롬프트는 앞 날짜를 적용한 앱을 기준으로 만들었어요.

| 날짜 | 파일 | 내용 |
|---|---|---|
| 2026-11-14 | [2026-11-14.md](2026-11-14.md) | 가민 워크아웃 파일(.fit) 받기(오늘·훈련표), 가이드 |
| 2026-11-15 | [2026-11-15.md](2026-11-15.md) | 인스타 스토리 하루 합산(랩표·그래프·AI 멘트), 대회 주 카드 접기, 가이드 공유 카드 제목·접기·순서 |
| 2026-11-16 | [2026-11-16.md](2026-11-16.md) | 훈련표 주간 결과, 체중 연동(측정 시각), 바디·오늘 화면 개선, 공통 UX, 대회 주 카드 리디자인, AI 코치 원포인트 레슨, 워크아웃 랩 자동 분할, 지난 훈련 계획 변경은 일정 조정에서 확인 후, 훈련표 끌어서 요일 바꾸기 |
| 2026-11-16 (추가분만) | [2026-11-16-past-plan.md](2026-11-16-past-plan.md) | 11/16 8장만 따로: 지난 훈련 계획 변경은 일정 조정에서 확인 후. 11/16을 이미 적용한 앱용(11/16 전체를 적용하면 필요 없음) |

- 모든 프롬프트는 복제본의 **버전 값(APP_VERSION·VLOG)을 바꾸지 않아요.** 복제본 버전은 복제 시점 값으로 고정이에요.
- 그날 원본을 고친 뒤 이 폴더의 그날 파일에 내용을 이어서 정리해요. 같은 날 여러 번 고쳐도 파일은 하루에 하나예요.
- 적용이 번거로우면, 원본을 새로 복제하고 가이드 → 백업으로 기록을 옮기는 방법이 가장 간단해요(최신 기능이 모두 들어와요).
