# 오답노트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사진으로 올린 오답을 AI가 옮기고 풀어 정답·풀이·핵심 개념·판서+음성 설명·비슷한 문제 복습까지 해 주는, 초3~고3 학생용 단일 HTML claude.ai 아티팩트.

**Architecture:** 로직은 `ohdap/src/`의 작은 ES 모듈(순수 함수 위주, node로 단위 테스트)로 쓰고, UI는 프레임워크 없이 DOM 헬퍼로 화면을 그린다. `tools/build.mjs`가 모듈과 KaTeX(JS·CSS·woff2 글꼴, base64)를 `ohdap/index.html` 하나로 합친다. AI·저장·음성은 아티팩트 기능(`sample`·`db`·`user`·`assets`·`tts`·`downloads`)을 `claude.use()`로 받아 쓰고, 없으면 대체 동작을 한다.

**Tech Stack:** 바닐라 JS(ES2022), Node 22 `node --test`, Playwright(사전 설치, `require('playwright')`), KaTeX 0.16.11(npm devDependency, 빌드 때 인라인).

**Spec:** `ohdap/docs/superpowers/specs/2026-11-20-ohdap-design.md` · UI 시안: https://claude.ai/artifact/7wRW1L9uK4yDvMKdMUTJui

## Global Constraints

- 결과물은 `ohdap/index.html` 한 파일. 외부 네트워크 요청은 Google Fonts(`IBM Plex Sans KR` 400/500/600/700, `STIX Two Text`)뿐. KaTeX는 인라인.
- 화면 문구는 모두 한국어. 휴대폰 세로(390px) 기준, 가로 스크롤 없음, 터치 영역 ≥44px(초등 모드 버튼 ≥60px, 본문 ≥17px).
- 색: 바탕 `#FAF8F3`, 글자 `#1C2333`, 보조 글자 `#4A5262`, 선 `#E6E1D6`, 주 색 `#1F5F4A`, 칠판 `#1F3A33`, 분필 `#F3F1E8`, 형광펜 `#F2C14E`, 맞음 파랑 `#1E3FA8`/`#E3EAFB`, 틀림 주황 `#8A3209`/`#FBEDE5`. 맞음/틀림은 색만이 아니라 ✓/✕ 아이콘과 글자로도 구분. 시안과 같은 모양을 따른다.
- 학년 값은 `'auto' | '초3'…'초6' | '중1'…'중3' | '고1'…'고3'`. 초3~초6이면 초등 모드(쉬운 말, 별, 큰 글자).
- 복습 간격 1·3·7·14일 → 정복. 비슷한 문제를 맞혀야 단계가 오르고, 틀리면 1일로.
- AI 결과는 "AI 풀이"로 표시하고 확신 말투를 쓰지 않는다. 옮긴 문제는 학생이 고칠 수 있다.
- 모든 `claude.use()` 결과는 `null`일 수 있다. `window.claude`가 없으면(파일로 열기) 모든 기능이 `null`.
- 사진은 긴 변 1600px·JPEG 0.85로 줄여 보낸다. db 문서는 256KiB 이하(사진은 db에 넣지 않는다).
- 모든 모듈의 최상위 이름은 번들 전체에서 겹치지 않는다(빌드가 `import`/`export`를 지우고 이어 붙인다).
- 앱 버전 `APP_VERSION`(시작 `'0.1.0'`)을 `src/main.js`에 두고 기능 변경마다 올린다.
- 게시는 보호자 계정. 아티팩트 1개 = 학생 1명.

## Review Focus

1. **AI가 모양이 틀린 JSON을 돌려줌**(필드 누락, steps 비어 있음, `visual` 이상) → 한 번만 다시 요청하고, 그래도 안 되면 "다시 정리" 버튼; 화면이 깨지지 않는다. (Task 6 `callJson` 재시도 테스트, Task 11 실패 화면 e2e)
2. **수식에 잘못된 LaTeX** (`$\frac{1}{$`) → 그 조각만 원문 글자로 보이고 나머지는 정상. (Task 5 `renderMathText` 오류 테스트)
3. **답 표기 차이**: `-1` vs `−1` vs `x=-1`, `1/2` vs `0.5`, `③` vs `3`, `3, -1` vs `-1,3` → 맞음으로 채점. (Task 4 테스트)
4. **db 없음/로그인 안 됨** → 이 기기 저장으로 동작하고 표시가 보이며, 나중에 db가 되면 옮기기가 중복 없이 된다. (Task 7 이전 테스트, Task 14 e2e)
5. **음성 기능 없음**(Safari·모바일 앱) → `speechSynthesis`, 그것도 없으면 시간 넘김으로 판서가 끝까지 재생된다. (Task 8 테스트)

### Task 6: AI 호출 (`ai.js`)

**Files:** Create `ohdap/src/ai.js`, `ohdap/tests/unit/ai.test.js`

**Interfaces:**
- Consumes: `isElementary`, `gradeLabel`(Task 2), `isValidColumn`(Task 5)
- Produces:
  - `class AiError extends Error { code: 'not_granted'|'rate_limited'|'bad_output'|'unavailable'|'unreadable' }`
  - `readPrompt({grade, subjectHint, myAnswer}): string` — 첫 줄 `TASK: read`. 결과 `{readable:boolean, reason?, problems:[{problem, choices, subject, unit, grade_guess}]}`
  - `solvePrompt({grade, subject, problem, choices, myAnswer, memo}): string` — 첫 줄 `TASK: solve`. 결과 `Solution`
  - `drillPrompt({grade, note}): string` — `TASK: drill`. 결과 `{problem, choices, answer, answer_short, steps}`
  - `gradePrompt({problem, answer, userAnswer}): string` — `TASK: grade`. 결과 `{correct:boolean, feedback:string}`
