이럴 땐 이렇게

자료를 올려 솔루션 등록하기
  1. 왼쪽 위 + 올리기에서 소개서·스펙 같은 파일을 끌어다 놓거나 골라 올립니다 (한 번에 {{ max_files }}개까지, 문서·사진·음성).
  2. AI 가 정리하는 동안 기다리면 {{ ont.label("intake") }} 화면이 정리안으로 바뀝니다. 저장하기 전에는 아무것도 등록되지 않습니다.
  3. 정리안 카드에서 "고치기"로 이름·내용을 고치고, 필요 없는 항목은 "이 항목 제외"를 체크한 뒤 "이대로 저장"을 누릅니다.

파일 없이 직접 쓰려면 {{ ont.label("solution") }} 직접 입력을 씁니다.

미팅 메모 남기기
  1. {{ ont.label("activity") }} 등록에서 메모를 붙여 넣거나 텍스트 파일(.txt, .md)을 고릅니다.
  2. "AI로 정리"는 제목·연결·후속 조치·{{ ont.label("customer_need") }} 초안을 만들어 주고, "원문만 저장"은 메모만 바로 저장합니다. "칸을 직접 채우기"로 모든 칸을 손으로 채울 수도 있습니다.
  3. 초안은 확인하고 고친 뒤 저장해야 반영됩니다. 고객·솔루션 화면의 "+ 활동 기록 쓰기"에서 시작하면 그 연결이 미리 골라져 있습니다.
니즈를 영업기회로 묶기
  1. 활동 기록 화면의 "{{ ont.label("customer_need") }}" 줄에 고객 이름(등록된 이름과 같게)과 내용을 적어 저장합니다. 이름이 등록된 고객과 맞으면 그 고객에 연결됩니다.
  2. {{ ont.label("opportunity") }} 만들기에서 고객을 고르면 그 고객의 아직 묶이지 않은 니즈가 나옵니다. 묶을 니즈를 체크해 저장합니다.
  3. 단계는 {{ ont.OPPORTUNITY_STAGES.values() | join(" · ") }} 중에서 상세 화면 위의 단계 막대로 바꿉니다 (순서 제한은 없습니다).
제안서 만들기
  1. {{ ont.label("proposal") }} 만들기에서 고객(필요하면 {{ ont.label("project") }}·{{ ont.label("opportunity") }})과 요청 메모를 적습니다. 고객 화면의 "+ 제안 만들기"로 시작하면 고객이 미리 채워집니다.
  2. AI 가 제안 방향을 몇 가지 만들면 하나를 골라 "이 방향으로 구체화"를 누르고, 대화로 범위·강조점을 다듬습니다.
  3. "구성안 만들기" 뒤 장별 내용을 고치고 확인 항목을 확인한 다음 "제안서 만들기"로 PPT 파일을 받습니다 ({{ ont.PROPOSAL_STEPS.values() | join(" → ") }}).
수주 후 프로젝트로 전환하기
  1. {{ ont.label("opportunity") }} 상세에서 단계를 "{{ ont.OPPORTUNITY_STAGES["won"] }}"로 바꿉니다.
  2. "프로젝트로 전환"을 눌러 새 {{ ont.label("project") }}를 만들거나 같은 고객의 기존 {{ ont.label("project") }}에 잇습니다. 전환은 영업기회마다 한 번만 됩니다.
내 할 일 보기
  1. 홈의 후속 조치 카드에서 "내 할 일"을 누르면 내가 맡은 것만 모아 보입니다 (주소 /?fu=mine).
  2. 내 것이 되려면 활동 기록의 후속 조치 "담당" 칸에 로그인 이름과 같은 이름을 적어야 합니다. 전체는 {{ ont.label("follow_up") }} 화면에서 봅니다.
검색하기
  1. 위쪽 검색칸에 이름이나 제목을 쓰고 Enter 를 누릅니다. 입력칸 밖에서 / 키를 눌러도 검색칸으로 옮겨 갑니다.
  2. 솔루션·고객·파트너·프로젝트·영업기회·BM·제안·활동 기록의 이름과 제목에서 찾습니다 (본문 내용은 찾지 않습니다). 각 목록 화면에는 따로 검색칸이 있습니다.
AI가 응답하지 않을 때 확인할 것
  1. 위쪽 줄의 AI 상태를 봅니다. "AI 사용 불가"는 AI 도구가 없거나 로그인이 풀린 것, "마지막 AI 작업 실패"는 그 작업만 실패한 것입니다.
  2. 기다리는 작업이 많으면 순서를 기다립니다. 실패한 작업은 화면의 "다시 시도"로 다시 보낼 수 있습니다.
  3. AI 가 안 되어도 조회와 직접 입력은 됩니다. {% if is_admin %}관리자는 시스템 점검에서 AI 점검을, AI 작업에서 대기열을 볼 수 있습니다.{% else %}계속 안 되면 관리자에게 알려 주세요.{% endif %}
