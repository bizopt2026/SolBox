이럴 땐 이렇게

자료를 올려 솔루션 등록하기
  1. 왼쪽 위 + 올리기에서 소개서·스펙 같은 파일을 끌어다 놓거나 골라 올립니다 (한 번에 {{ max_files }}개까지, 문서·사진·음성).
  2. AI 가 정리하는 동안 기다리면 {{ ont.label("intake") }} 화면이 정리안으로 바뀝니다. 저장하기 전에는 아무것도 등록되지 않습니다.
  3. 정리안 카드에서 "고치기"로 이름·내용을 고치고, 필요 없는 항목은 "이 항목 제외"를 체크한 뒤 "이대로 저장"을 누릅니다.

파일 없이 직접 쓰려면 {{ ont.label("solution") }} 직접 입력을 씁니다.

음성 파일만 올렸다면: 받아쓰기가 꺼져 있으면 {{ ont.label("intake") }}은 실패가 아니라 "{{ ont.INTAKE_ARCHIVED_LABEL }}" 으로 남고 원본은 그대로 보관됩니다. 회의 내용을 글자로 풀어 다시 올리거나, 관리자에게 받아쓰기를 켜 달라고 요청하세요. 켜진 뒤에는 그 묶음 화면에서 "다시 정리"를 누르면 됩니다. 음성과 문서를 함께 올렸다면 문서만 정리되고 음성에는 "받아쓰기 필요" 표시가 붙습니다.

같은 파일을 다시 올렸다면: 이미 저장한 파일이면 정리안 카드에 "같은 파일을 n월 d일에 올려 저장했습니다"라고 알리고, 그 파일이 원문인 활동 기록은 처음부터 "이 항목 제외"가 켜져 있습니다 (풀면 다시 저장됩니다). 솔루션에 이미 있는 자료와 내용이 같은 파일은 자료로 다시 만들지 않고 건너뜁니다.

미팅 메모 남기기
  1. {{ ont.label("activity") }} 등록에서 메모를 붙여 넣거나 텍스트 파일(.txt, .md)을 고릅니다.
  2. "AI로 정리"는 제목·연결·후속 조치·{{ ont.label("customer_need") }} 초안을 만들어 주고, "원문만 저장"은 메모만 바로 저장합니다. "칸을 직접 채우기"로 모든 칸을 손으로 채울 수도 있습니다.
  3. 초안은 확인하고 고친 뒤 저장해야 반영됩니다. 고객·솔루션 화면의 "+ 활동 기록 쓰기"에서 시작하면 그 연결이 미리 골라져 있습니다.
니즈를 영업기회로 묶기
  1. 활동 기록 화면의 "{{ ont.label("customer_need") }}" 줄에 고객 이름(등록된 이름과 같게)과 내용을 적어 저장합니다. 이름이 등록된 고객과 맞으면 그 고객에 연결됩니다.
  2. {{ ont.label("opportunity") }} 만들기에서 고객을 고르면 그 고객의 아직 묶이지 않은 니즈가 나옵니다. 묶을 니즈를 체크해 저장합니다.
  3. 단계는 {{ ont.OPPORTUNITY_STAGES.values() | join(" · ") }} 중에서 상세 화면 위의 단계 막대로 바꿉니다 (순서 제한은 없습니다).
제안서 만들기
  1. {{ ont.label("proposal") }} 만들기에서 고객(필요하면 {{ ont.label("project") }}·{{ ont.label("opportunity") }})과 요청 메모를 적습니다. 고객 화면의 "+ 제안 만들기"로 시작하면 고객이 미리 채워집니다.
  2. AI 가 제안 방향을 몇 가지 만들면 하나를 골라 "이 방향으로 구체화"를 누르고, 대화로 범위·강조점을 다듬습니다.
  3. "구성안 만들기" 뒤 장별 내용을 고치고 확인 항목을 확인한 다음 "제안서 만들기"로 PPT 파일을 받습니다 ({{ ont.PROPOSAL_STEPS.values() | join(" → ") }}).
  4. 고객에게 보내는 파일은 "고객용 PPT"입니다 (발표자 노트가 없습니다). "내부 검토용 PPT"는 노트에 출처와 확인할 점이 들어 있어 보내면 안 됩니다. 보내기 전에 고객용 PPT 를 처음부터 끝까지 직접 읽어 보세요. 앱은 작성자에게 하는 말처럼 보이는 줄("확인 필요" 같은 말투)과 채우지 않은 자리표시(XX%, ○○)만 옮기고 내부 경로를 빼 줍니다. "초안"·"내부 검토용" 같은 내부 낱말은 걸러 내지 않으니 직접 읽어 확인해 주세요. 마무리 장의 담당·연락처는 제안서를 만든 사람의 이름과 내 정보의 연락처로 채워집니다.
수주 후 프로젝트로 전환하기
  1. {{ ont.label("opportunity") }} 상세에서 단계를 "{{ ont.OPPORTUNITY_STAGES["won"] }}"로 바꿉니다.
  2. "프로젝트로 전환"을 눌러 새 {{ josa(ont.label("project"), "을/를") }} 만들거나 같은 고객의 기존 {{ ont.label("project") }}에 잇습니다. 전환은 영업기회마다 한 번만 됩니다.
프로젝트 상태 정하기
  1. {{ ont.label("project") }}를 등록하거나 고칠 때 "{{ ont.prop("project", "status") }}"을 목록({{ ont.PROJECT_STATUSES.values() | join(" · ") }})에서 고릅니다. 정하지 않아도 됩니다 ("선택 안 함").
  2. 예전에 직접 적어 둔 상태는 지워지지 않고 "(이전 입력)" 이 붙어 보입니다. 고칠 때 그대로 두면 유지되고, 목록 값으로 바꿀 수도 있습니다.
내 할 일 보기
  1. 홈의 후속 조치 카드에서 "내 할 일"을 누르면 내가 맡은 것만 모아 보입니다 (주소 /?fu=mine).
  2. 내 것이 되려면 활동 기록의 후속 조치 "담당" 칸이 내 이름(뒤에 대리·과장·팀장·님 같은 직함이 붙어도 됩니다)이어야 하고, 같은 이름의 사용자가 하나뿐일 때만 이어집니다. 담당이 비었거나 다르게 적혔다면 그 줄의 "내 할 일로" 버튼으로 내 이름으로 바꿀 수 있습니다. AI 가 정리할 때는 메모에서 "제가 …하기로" 처럼 글쓴이가 맡은 일에 글쓴이(올린 사람) 이름을 담당으로 적습니다. 전체는 {{ ont.label("follow_up") }} 화면에서 봅니다.
검색하기
  1. 위쪽 검색칸에 이름이나 제목을 쓰고 Enter 를 누릅니다. 입력칸 밖에서 / 키를 눌러도 검색칸으로 옮겨 갑니다.
  2. 솔루션·고객·파트너·프로젝트·영업기회·BM·제안·활동 기록의 이름과 제목은 물론 소개·설명·메모·연락처·정리본·원문과 후속 조치·고객 니즈의 글에서도 찾고, 이름이 아닌 칸에서 맞았으면 그 칸의 이름과 맞은 글 둘레를 보여 줍니다. 각 목록 화면에는 따로 검색칸이 있습니다.
  3. 솔루션·활동 기록·고객·파트너 목록의 "유래"(전체 / 올리기 / 리서치 / 직접 입력)로 올리기나 리서치로 만든 기록만 모아 볼 수 있습니다.
"저장하지 않았습니다" · "잠시 후 다시 시도해 주세요"가 나올 때
  1. 두 화면 모두 아무것도 저장되지 않았다는 뜻입니다(솔루션 자료를 여러 개 올리다 중간에 막힌 경우만 예외로, 그때는 어느 파일을 저장하지 못했는지 화면에 적습니다). "뒤로 가기"(단추가 안 보이면 브라우저의 뒤로 가기)를 누르면 쓰던 내용이 그대로 남아 있습니다.
  2. "잠시 후 다시 시도"는 다른 사람이 저장하는 중이라는 뜻이니 잠깐 뒤에 다시 저장합니다. 첨부했던 파일은 다시 골라야 합니다. 제안 건 만들기의 방향 작업, 제안 대화의 메시지, 올리기 "다시 정리"의 고친 메모도 함께 저장되지 않으니, 다시 보내도 한 번만 들어갑니다. 예외는 솔루션 자료를 여러 개 올릴 때입니다: 저장된 파일이 하나도 없는 채로 막히면(이미 있는 자료나 큰 파일로 건너뛴 파일은 저장이 아닙니다) 이 화면이 뜨고, 앞 파일이 저장된 뒤에 막히면 "저장하지 못한 파일" 안내가 뜨니 그 파일만 다시 올리세요. 올리기 "다시 정리"는 고친 메모가 남지 않지만 파일 읽기 상태는 갱신돼 있을 수 있습니다.
비밀번호 바꾸기
  1. 왼쪽 메뉴 맨 아래 내 이름(또는 내 정보)을 누릅니다.
  2. 현재 비밀번호와 새 비밀번호(8자 이상, 아이디와 같거나 같은 글자 하나로만 된 것은 안 됨)를 두 번 쓰고 "비밀번호 바꾸기"를 누릅니다. 다른 곳에서 로그인한 상태는 끝나고 지금 화면은 그대로 쓸 수 있습니다.
  3. 비밀번호를 잊었다면 관리자에게 알려 새 비밀번호를 받습니다. 관리자가 정해 준 비밀번호로 로그인하면 먼저 비밀번호를 바꾸는 화면이 나옵니다.
AI가 응답하지 않을 때 확인할 것
  1. 위쪽 줄의 AI 상태를 봅니다. "AI 사용 불가"는 지난 AI 작업이 AI 도구가 없거나 로그인이 풀려 실패했다는 뜻이고, "마지막 AI 작업 실패"는 그 작업만 실패한 것입니다. "AI 꺼짐"은 서버의 AI 작업 처리기가 꺼진 것입니다.
  2. 기다리는 작업이 많으면 순서를 기다립니다. 실패한 작업은 화면의 "다시 시도"로 다시 보낼 수 있습니다.
  3. AI 가 안 되어도 조회와 직접 입력은 됩니다. "AI 꺼짐"이면 AI 를 쓰는 버튼이 눌리지 않고 이유가 화면에 적혀 있습니다. 이미 열어 둔 화면에서 보내면 쓴 글(메모·대화·지시)을 채운 화면이 다시 나오니 글은 잃지 않습니다. 올린 파일은 보관만 되고 정리는 시작되지 않으니, 처리기가 켜진 뒤 올리기 묶음에서 "정리 시작"을 누릅니다. "AI 사용 불가"는 버튼이 그대로 눌립니다: 다시 시도하면 연결을 다시 확인하고, 성공하면 안내가 사라집니다(올린 파일은 보관되고 정리를 바로 시도하며, 실패하면 "다시 정리"). 계속 실패하면 관리자가 "AI 연결 확인"을 합니다. {% if is_admin %}관리자는 시스템 점검에서 AI 점검을, AI 작업에서 대기열을 볼 수 있습니다.{% else %}계속 안 되면 관리자에게 알려 주세요.{% endif %}
